# 리그 도메인 룰

정규리그 운영 규칙 상세. 루트 CLAUDE.md의 "리그 작업 시 주의" 항목이 요약본이다.

## 리그 구성
- 생성 가능한 종류는 정규리그 Summer / Winter (`LeagueType`에 `jongchoe`, `individual`도 있으나 미노출)
- **팀장 수는 리그별 설정값**(`leagues.captain_count`, 기본 4) — 4로 하드코딩 금지
- 팀장 순번: 티어가 낮을수록, 승률이 낮을수록 앞 순번 (우선 선택권)
- 스네이크 드래프트: 1→2→3→4→4→3→2→1→… (팀장 수만큼 왕복)
- 리그 상세 입력 탭 순서: 리그 설명 → 팀장 선출 → 시드권자 → 경기별 맵 선택 → 엔트리 포인트

## 맵 가이드라인
| 경기 | 맵 |
|------|-----|
| 1·4·5·6경기 | 1개 고정 |
| 2·3경기 | 밴픽 풀 2~3개 중 택1. 양팀 각 1개 밴, 낮은 티어 팀의 밴 적용, 동티어 다른 밴 → 사다리타기 |
| 7경기 | 에이스 결정전. 1~6경기에 쓰인 맵 중에서 따로 고른다 (맵 배정 대상 아님) |

- 각 맵은 한 경기에만 배정 가능 (중복 불가). 2·3경기는 최소 2개 선택해야 저장됨

## 팀원 지목식 (DraftView)
1. 선수 풀에서 팀으로 드래그 앤 드롭 (스네이크 드래프트)
2. 모든 픽 완료 후 "시드권 교체" 모드 진입 — 1번 시드권자가 적용 순서를 결정
3. 시드권 교체까지 끝난 상태에서 저장하면 최종 저장 → `draft_completed = true`, 이후 읽기 전용

- Supabase Realtime 채널 `draft-room:{leagueId}`로 동기화 (여러 참가자가 동시 관전)
- 최종 저장 시 `league_player_snapshots`에 티어/종족/군인여부 스냅샷을 남긴다

### 시드권 규칙
- 시드권을 행사하는 팀의 멤버를 **먼저** 선택 → 상대 팀 멤버 선택 → 교체
- 시드권 보유자 본인, 각 팀의 1번 픽은 교체 불가
- 두 티어 이상 차이나면 불가 — 판정은 `|tierPoint(a) - tierPoint(b)| >= 2`,
  0.5 단위 체계이므로 여기서 "두 티어"는 알파벳 두 단계(A+ 5 ↔ C+ 3)를 뜻한다
- 세 픽 이상 차이나면 불가 (상대 3번 픽을 가져오려면 우리 4번 픽 이상을 내보내야 함)
- 교체된 멤버는 이후 이동 불가 (잠금). 검증 로직은 `src/composables/useSeedSwap.ts`

## 엔트리 제출 룰
상위티어 편중을 막기 위해 티어별 포인트 합계에 한도를 둔다. 팀장이 리그참여(`/participate`)에서 제출.

| 경기 | 유형 | 인원 | 한도 |
|------|------|------|------|
| 1·2·3·5·6경기 | 개인전 | 1명 | `entry_solo_max` (기본 16) |
| 4경기 | 팀전 | 2명 | `entry_team_max` (기본 7) |
| 7경기 | 에이스 결정전 | — | 엔트리 미포함 |

- 개인전+팀전 합산 한도 = `entry_total_max` (기본 23)
- 한도는 `leagues` 테이블의 리그별 설정값이며 엔트리 포인트 탭에서 관리자가 변경한다
